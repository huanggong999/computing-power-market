# 变更提案: AutoDL 实例管理功能

**变更名称**: autodl-instance-manager
**提交日期**: 2026-05-24
**作者**: Claude
**状态**: 设计中

## 1. 背景与问题

当前系统缺少对已购买 GPU 实例的管理功能。用户购买算力资源后，无法查看实例状态、执行开机/关机/重启等操作，也无法查看实例详情和监控信息。

这导致用户需要跳转到其他平台或联系客服来管理自己的实例，严重影响用户体验。

## 2. 目标

实现一个完整的实例管理功能模块，参考 AutoDL (https://www.autodl.com/console/instance/list) 的界面和交互设计：

1. **实例列表页**: 展示用户所有实例，支持筛选、分页
2. **实例操作**: 支持开机、关机、重启、释放(删除)实例
3. **批量操作**: 支持多选实例进行批量操作
4. **实例详情**: 侧边抽屉展示实例详细信息、SSH信息、监控图表
5. **状态管理**: 实时展示实例状态(运行中、已关机、创建中等)

## 3. 范围

### 3.1 纳入范围

- 实例列表展示（表格形式）
- 实例状态显示（带颜色标识）
- 实例筛选（按GPU类型、区域、状态）
- 实例搜索（按名称）
- 分页功能
- 单实例操作：开机、关机、重启、释放
- 批量选择/批量操作
- 实例详情抽屉（基础信息、资源配置、SSH信息）
- 监控图表（GPU使用率、显存占用）

### 3.2 不纳入范围

- 创建新实例功能（已有独立页面）
- 实例续费功能（由订单系统处理）
- 实例迁移功能
- 高级监控告警

## 4. 预期行为

### 4.1 用户流程

1. 用户登录后进入「控制台 > 实例管理」
2. 页面加载实例列表，默认显示全部实例
3. 用户可：
   - 使用筛选栏按条件过滤实例
   - 点击操作按钮执行开机/关机/重启/释放
   - 勾选多个实例进行批量操作
   - 点击实例名称查看详情抽屉
4. 操作后显示 loading/进度，完成后刷新状态
5. 实例详情抽屉展示：
   - 基础信息（ID、UUID、创建时间等）
   - 资源配置（GPU/CPU/内存/磁盘）
   - SSH连接信息（一键复制）
   - 实时监控图表

### 4.2 状态流转

```
创建中 → 运行中 → 已关机
           ↓      ↓
         重启中  开机中
           ↓      ↓
         运行中  运行中
```

### 4.3 错误处理

- 操作失败时显示具体错误信息
- 网络异常时支持重试
- 批量操作部分失败时显示成功/失败统计

## 6. 风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 状态同步延迟 | 中 | 操作后轮询状态，刷新间隔2秒 |
| 批量操作超时 | 中 | 分批执行，每批最多10个实例 |
| 监控数据量大 | 低 | 图表展示最近1小时数据，支持自定义时间 |
| SSH信息泄露 | 高 | 密码默认隐藏，点击显示并自动复制 |

## 7. 成功标准

1. ✅ 用户可查看所有实例列表
2. ✅ 筛选和搜索功能正常工作
3. ✅ 单实例操作（开机/关机/重启/释放）可用
4. ✅ 批量操作支持最多10个实例
5. ✅ 实例详情抽屉展示完整信息
6. ✅ 监控图表正常加载和显示
7. ✅ 所有操作有 loading 和错误提示
