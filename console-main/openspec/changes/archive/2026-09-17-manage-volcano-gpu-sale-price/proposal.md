## 为什么

后台管理端和官网算力市场的火山云 GPU 目录来自同一份上游数据，但当前没有平台售价维护能力，官网只能直接展示火山实际价格。运营需要独立调整对客价格，同时下单仍必须按火山实时价格确认资源可售并记录成本口径，避免把销售价和火山成本价混用。

## 变更内容

- 新增火山云 GPU 平台售价配置，按 `地域 + 实例规格 + 计费周期` 维护，支持后台管理端查询、编辑、启停和恢复默认价。
- 管理端火山云 GPU 目录继续展示火山实际价，并增加平台售价、差价/溢价等运营信息。
- 官网火山云目录接口在保留 `price` / `priceMonthly` 火山实际价口径的同时，返回平台售价字段；无有效配置时默认使用火山实际价。
- `computeListNew` 火山云数据展示、费用试算和下单扣费使用后台维护的平台售价。
- 后台下单服务在下单时重新查询火山实时价格：查不到或价格无效则拒单；订单与订单资源快照记录火山实际价和平台售价，火山实际价作为成本/上游价，平台售价作为用户应付价。

## 功能 (Capabilities)

### 新增功能

- `volcano-gpu-sale-price-management`: 后台管理端维护火山云 GPU 平台售价，并让官网目录展示、费用计算、余额扣费和订单快照使用该售价，同时保留下单时实时校验的火山实际价格。

### 修改功能

无已有 OpenSpec 能力需要修改。

## 影响

- 后端 `GpuSchedulerApiClient` 目录聚合、火山价格查询逻辑，以及管理端/官网目录接口。
- 新增平台售价表、实体、Mapper、Service 和 Flyway 迁移。
- 后台管理端 `ux-admin-main/src/views/gpu/volcano/index.vue` 与 API 模块增加售价编辑能力。
- 官网 `ux-user-main/src/view/computeList/new.vue`、`ux-user-main/src/view/computeRent/index.vue` 的火山云价格选择、费用计算和下单参数。
- `PcGpuRentController` 外部 GPU 下单计费与订单快照逻辑。
