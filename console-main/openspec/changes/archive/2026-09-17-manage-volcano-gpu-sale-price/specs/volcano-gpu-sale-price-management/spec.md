## 新增需求

### 需求:后台维护火山云GPU平台售价
系统必须允许管理员按地域、火山实例规格和计费周期维护火山云 GPU 的平台售价，并支持启用、停用和恢复默认火山价格。

#### 场景:保存平台售价
- **当** 管理员在火山云 GPU 管理页选择某个地域和实例规格，为指定计费周期保存大于零的平台售价
- **那么** 系统必须保存或更新该唯一售价配置，并在后续目录返回中使用该价格

#### 场景:停用平台售价
- **当** 管理员停用某个火山云 GPU 售价配置
- **那么** 系统必须在官网目录、费用计算和下单计费中回退使用火山实际价格

#### 场景:目录规格消失
- **当** 火山云上游目录不再返回某个已配置售价的实例规格
- **那么** 系统必须忽略该配置且不得影响其他目录数据的展示或下单

### 需求:目录返回双价格
火山云 GPU 目录必须同时返回火山实际价格和平台售价，且不得用平台售价覆盖火山实际价格字段。

#### 场景:存在平台售价
- **当** 目录中的实例规格存在启用的平台售价配置
- **那么** 系统必须保留 `price` / `priceMonthly` 的火山实际价，并在平台售价字段中返回配置值

#### 场景:未配置平台售价
- **当** 目录中的实例规格没有启用售价配置
- **那么** 系统必须将平台售价字段设置为火山实际价格；火山价格无效时平台售价同样无效

#### 场景:管理端查看价格
- **当** 管理员打开火山云 GPU 管理页
- **那么** 系统必须展示火山实际价、平台售价和两者的差额或溢价信息

### 需求:官网使用平台售价计价
官网算力市场火山云数据的列表展示、费用预览、订单确认和余额扣费必须使用后台维护的平台售价。

#### 场景:列表展示
- **当** 用户浏览 `computeListNew` 且火山云规格存在启用平台售价
- **那么** 页面必须按平台售价展示单价并计算页面预估金额

#### 场景:租用确认
- **当** 用户选择火山云规格进入租用确认页
- **那么** 页面必须使用当前服务端目录解析出的平台售价展示费用；不得使用浏览器提交的价格作为最终扣费金额

#### 场景:计费周期切换
- **当** 用户切换火山云规格的计费周期
- **那么** 页面必须按对应计费周期的平台售价重新解析价格；无对应售价时必须回退火山实际价

### 需求:下单实时校验火山价格
创建火山云 GPU 订单时，系统必须重新查询火山实时价格并校验有效性，且订单应付金额必须由服务端按平台售价计算。

#### 场景:实时价格有效
- **当** 用户提交火山云 GPU 租用订单且服务端查到有效火山实时价格和平台售价
- **那么** 系统必须按平台售价计算用户应付总额并允许进入创建流程

#### 场景:实时价格无效
- **当** 用户提交订单时服务端查不到该规格、火山价格不存在或火山价格不大于零
- **那么** 系统必须拒绝创建订单并返回价格不存在或已变化的错误

### 需求:订单记录双价格快照
火山云 GPU 订单必须记录火山实际价格、平台售价、应付金额和溢价信息，作为成本与收入对账依据。

#### 场景:订单创建成功
- **当** 火山云 GPU 订单创建成功
- **那么** 订单主表金额必须等于平台售价计算出的应付总额，订单资源与配置快照必须包含火山实际价、平台售价、单卡/单规格溢价和计费周期

#### 场景:未配置平台售价
- **当** 火山云 GPU 订单创建时没有启用平台售价配置
- **那么** 订单快照中的平台售价必须等于火山实际价，且溢价必须为零
