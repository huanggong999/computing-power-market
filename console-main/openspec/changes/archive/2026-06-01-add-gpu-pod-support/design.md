# 设计文档：GPU Pod 实例管理集成

## 概述

本设计文档描述了如何在算力市场平台中集成 GPU Pod 实例管理功能。该功能允许用户通过统一的界面管理 GPU Pod 算力资源，包括实例的创建、启动、停止、重启、释放等生命周期管理操作，以及 SSH 信息查看、日志查看、定时关机等高级功能。

GPU Pod 服务使用 JWT Bearer Token 认证，后端需要实现 Token 管理：

```
┌─────────────────────────────────────────────────────────────┐
│                     JWT 认证流程                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ┌─────────────────┐     ┌─────────────────────────────┐   │
│  │  ai-cloud-system │     │      GPU Pod 服务          │   │
│  │                 │     │    124.174.46.14:8000      │   │
│  │  ┌───────────┐  │     │                             │   │
│  │  │Token缓存  │  │     │  ┌─────────────────────┐   │   │
│  │  │(内存/Redis)│ │     │  │  POST /api/v1/auth/token │ │   │
│  │  └─────┬─────┘  │     │  │                     │   │   │
│  │        │        │     │  │ 请求:               │   │   │
│  │        ▼        │     │  │  {                 │   │   │
│  │  ┌───────────┐  │     │  │    tenant_id,     │   │   │
│  │  │GpuPodClient│ │ ─────▶│  │    api_key        │   │   │
```

## 技术实现要点

### 1. JWT Token 管理

由于 GPU Pod 服务需要 JWT 认证，后端需要实现 Token 的获取和缓存机制：

- 使用 Caffeine 或 Redis 缓存 Token
- Token 过期前自动刷新
- 支持并发场景下的 Token 刷新同步

### 2. HTTP 客户端配置

使用 Spring 的 `RestTemplate` 或 `WebClient` 调用 GPU Pod 服务：

- 配置连接池和超时参数
- 实现请求/响应拦截器（日志、重试）
- 异常处理和熔断降级

### 3. 数据转换层

设计专门的数据转换组件，负责 GPU Pod 数据格式与前端期望格式之间的转换：

- 使用 MapStruct 或手动转换
- 统一处理字段映射、单位转换、枚举转换
- 支持双向转换（请求时和响应时）

## 安全考虑

1. **API 认证**：所有接口沿用现有的 Spring Security + JWT 认证机制
2. **敏感信息**：SSH 密码等敏感信息在日志中脱敏处理
3. **访问控制**：校验当前用户是否有权限操作指定实例
4. **请求限流**：对 GPU Pod 服务的调用实施限流，防止过载

## 部署考虑

1. **配置管理**：GPU Pod 服务的地址、密钥等配置通过环境变量或配置中心管理
2. **健康检查**：增加 GPU Pod 服务健康检查接口
3. **监控告警**：对接口调用量、响应时间、错误率进行监控
4. **日志追踪**：实现分布式链路追踪，方便问题定位
